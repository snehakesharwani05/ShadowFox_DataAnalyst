# 🍔 Food Delivery Customer & Restaurant Analytics

An intermediate-level data analytics project that analyzes food delivery orders, revenue, restaurant performance, delivery efficiency, cancellations, order behaviour, and promotional activity.

## 🚀 Live Dashboard

🔗 **[View Live Dashboard](https://food-delivery-analytics-2005.streamlit.app/)**

## 🎯 Project Objective

The goal of this project is to transform raw food delivery data into meaningful business insights and recommendations.

Key questions analyzed:

- Which restaurants generate the most revenue?
- How does revenue change over time?
- Which cities have higher cancellation rates?
- How does delivery time relate to cancellations?
- Which payment methods contribute the most revenue?
- How do promotions and free delivery affect order value?
- How does order size relate to spending?
